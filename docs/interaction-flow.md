# 药箱交互重构

## 目标与边界

首页服务于查看和寻找库存，不常驻录入表单。OCR 是输入助手，而不是药品数据库或用药决策工具。不推测药品名称、到期日期或疗效，不自动合并同名记录。

## 信息流

```text
我的药箱
  ├─ 搜索 / 筛选 → 药品卡片 → 详情
  │                            ├─ 更新余量 → 详情
  │                            ├─ 编辑 / 补拍 → 核对页 → 保存 → 药箱定位
  │                            └─ 移出药箱 → 药箱提示撤销
  └─ 添加 → 拍照 / 相册 / 手动
              → 核对页 → 保存成功 → 药箱定位
```

- 空状态提供添加入口；有数据时列表是主角。
- 首页只保留照片、名称、有效期状态和带单位的余量，不展示长功效、备注和 OCR 原文。
- 筛选“临期”是到期日在今天至未来 90 天之间，含边界；已过期是到期日早于今天。
- 日期未知单独呈现，绝不等同已过期或有效。
- 每条记录表示一份库存。同名但不同有效期可以分别保存。

## 拍照与核对

1. 拍药盒正面，可继续补拍盒底、侧面有效期。
2. 将照片复制到应用私有持久目录，不依赖相册临时授权或缓存寿命。
3. ML Kit 本地识别，显示原文和明确标签匹配到的候选字段。
4. 药名只匹配名称标签，不取第一行；有效期只匹配“有效期至”等明确到期标签，不使用孤立日期、生产日期或“24 个月”。
5. 候选通过“采用”显式写入空字段；已有填写时禁用采用，不覆盖人工内容。
6. 用户对照照片核对名称和有效期后勾选确认。字段仍可手动填写或留空。
7. 保存过程中禁用重复提交与离开；数据库完成写入后才返回药箱并提示成功。失败保留草稿。

没有候选不代表没有识别到文字；可以查看原文后手动录入。识别失败、取消拍照或拒绝权限不会阻断手动录入。首次授予相机权限后直接继续拍摄。

## 数据规则

- 名称必填。
- 到期日可用日期选择器填写，或手动输入严格的 `YYYY-MM-DD`、`YYYY-MM` 月份精度（以该月末计算）。不支持将期限与生产日期自动换算为到期日。
- 余量是非负整数，有数量必须选单位。空值表示未知，0 表示已用完。不跨单位合计，也不把所有单位统一定义为 `≤3` 低余量。
- 包装功效、备注渐进展开，功效文字不作为用药建议。
- 多张照片最多 12 张，支持放大和双指缩放；照片顺序保留。
- 草稿、页面、筛选等经 SavedStateHandle 保存，支持旋转和 Android 保存状态后的进程重建；不承诺强制停止或清除任务后的草稿恢复。
- 返回未保存的编辑页需确认放弃。添加或更新成功返回全部库存并定位记录。
- 移除需确认；通过随后提示条可以撤销。当前仅保留最近一次移除的内存记录，不是长期回收站。

## 旧版本兼容

Room 版本 2 → 3 仅增加数量单位、多图及更新时间字段，保留旧字段和创建时间。移除 destructive fallback，缺少迁移时显式失败而不是清空记录。

- 原数字余量保留，单位为空时显示“单位待补充”。
- 无法解析的旧有效期保留原文并提示核对，不参与有效/过期判断。
- 旧缓存照片还存在且可读取时转存私有目录；已经丢失的照片无法恢复。
- 更新余量或编辑资料不改创建时间，不自动合并同名药品。

## 必要 UT 与按需检查

仅保留 5 个纯规则 UT，集中在日期精度与无效值、临期边界、表单/余量校验、明确标签候选和生产日期排除。不引入额外测试框架，不保留新增的 UI／仪器测试套件。

构建和 Lint 用于发现编译及静态问题。页面、旧数据迁移、权限与 OCR 实际照片效果在专用设备上按需检查，不以规则 UT 代替实际功能验证。

## GitHub 应用更新

- 首页右上角“更新”打开对话框并检查公开仓库最新正式 Release；不在启动时后台联网。
- 显示当前版本；无 Release、当前已最新、检查失败分别提示，不阻断药箱操作。
- 有新版时展示版本、大小、说明，用户点击后才下载；下载进度跨旋转保留，关闭对话框不取消下载，进程终止后需重新检查/下载。
- 下载到专用缓存目录，仅通过 HTTPS 获取本仓库资源；校验 SHA-256、大小、包名、版本和当前签名，不触碰 Room 或照片目录。
- 校验通过后用户点“安装更新”，必要时打开 Android 未知来源授权页；返回后请求系统安装，最终仍由用户确认。拒绝授权、取消安装或失败不清除药箱。
- 历史调试 APK 可能使用不同签名；不一致时明确阻止覆盖并提醒先保留/备份数据，绝不自动卸载。备份导出仍不在本次范围。
- main CI 使用固定私有调试签名，发布带校验元信息的公开 Release；PR 不访问该签名、不发布。新增 3 个纯更新规则 UT，不引入测试框架。

## 后续而非本次范围

真实药盒 OCR 评估、条码/药品库、批次管理、备份导出、照片单独删除与未保存照片清理、服药计划、推送提醒、可配置低余量阈值。
