# 手绘药箱：信息层级与视觉语言

## 首页先回答「家里有没有这盒药」

- 只保留搜索、必要的异常提醒、库存清单和一个添加入口；不常驻大插画、统计仪表盘或标签墙。
- 清单显示药名与识别所需的品牌/规格摘要。过期、90 天内到期、日期待补充/待核对及已用完保持可见；正常记录的完整有效期、数字余量、位置、全部标签放进详情。
- 搜索期间不显示无关的全局提醒。无搜索且无筛选时，若有过期/临期库存，显示一条应用内提醒；点击进入「需要留意」筛选。不是系统通知，也不代表用药建议。
- 有效期与标签放在按需底部筛选面板，与搜索取交集；清除条件和无结果恢复保留。
- 添加方式在点击后展开；检查更新位于首页「更多 → 检查更新」，不在启动时后台联网。

## 详情回答「是不是这一盒，是否过期，还剩多少，在哪里」

- 名称、品牌/规格、有效期、余量和位置是第一层。余量仍区分未知、0、带单位和单位待补充。
- 更新余量使用底部面板，保留当前药品上下文。写入期间阻止退出与重复提交；成功后更新详情，失败保留输入。
- 包装/药品资料、全部标签、照片、说明书原文、备注和 OCR 原文按组展开。照片可放大、双指缩放；说明书正文不截断。
- 说明书免责声明始终可见。空内容不解释为没有禁忌或不良反应。
- 编辑位于顶部，补拍在照片分组内；移除及撤销保留。

## 录入是渐进补充

- 先名称和有效期，拍照与相册可以辅助核对；识别候选仍需显式采用，不覆盖人工填写。
- 余量、位置、身份资料、标签、说明书和备注按需展开；校验失败会展开相关分组。
- 保存固定在底部，跟随 IME 留出区域；表单可滚动。未保存返回确认，返回编辑之前的详情或药箱。
- 只改变呈现，不增加数据字段或修改 Room 迁移。旧记录、照片和说明书原文保留。

## 统一笔性，而不是统一圆角

- 桌面图标：手绘「药」字小签，暖白底、草木墨色；提供圆形/常规自适应图标与单色主题图标。
- 首页字标：原创「药箱」笔画路径；短静态标题/按钮使用 Long Cang，动态药名、数量及说明书使用完整字符的 LXGW WenKai Lite。
- 手绘边框留口、分割线轻微起落、按钮有淡色笔触，内容与触控区域保持稳定。图形不使用随机抖动滤镜。
- 无照片时仅显示通用药盒线稿，不根据药名或标签猜剂型。完整白描只用于空药箱；实际包装照片优先。
- 动效限于约 180–220ms 的页面轻推/淡入、资料展开、选中记录反馈，以及 Material 底部面板；Compose 使用系统动画时长设置。没有循环装饰动画或拟真翻页。
- 正文与次级信息使用深色墨色，药名和说明书不使用草写/缺字的子集字体。短标题字体子集只服务静态 UI，不用作用户数据字体。

## 资源来源与许可

- 字标、药盒/空状态插画及手绘轮廓为本任务原创路径，转换为 Android VectorDrawable；资源位于 `app/src/main/res/drawable/`。
- **LXGW WenKai Lite Regular**：https://github.com/lxgw/LxgwWenKai-Lite ，完整字体打包为 `res/font/paper_text.ttf`，便于离线显示药品资料。未安装系统字体。
- **Long Cang**：https://github.com/googlefonts/longcang ，本任务按静态 UI 文本与字符子集生成 `res/font/paper_display.ttf`，减小体积；用户文本由完整字体显示。
- 两者为 SIL Open Font License 1.1；版权与许可证随 APK 保留在 `app/src/main/assets/font-licenses/`。生成子集使用 fontTools，不加入应用/测试依赖。
- 完整中文字体会增大 APK；这是离线保留中文字形与手绘文本风格的取舍，不引入网络字体请求。

## 验证界限

UT 验证原日期/余量/标签/资料/更新核心规则，构建与 Lint 验证编译和静态约束。不新增 UI／仪器测试框架。

本地 Maestro smoke 已按新布局调整：余量分组展开、库存数量在详情断言、重启后再次进入详情验证持久化。运行前仍要求用户明确允许本次清空专用 AVD 的本 App 测试数据。未获该授权时不得安装、清空或宣称设备验收通过。

尚需实际设备检查：软键盘、系统大字体、TalkBack、系统返回/动画设置、真实照片 OCR、升级数据保留及图标在不同桌面形状下的效果；构建通过不等于这些已实测。
