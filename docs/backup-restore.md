# 药箱备份与换机

入口：**首页 → 更多 → 备份与换机**，空药箱也可点击「从旧手机导入药箱」。使用 Android 系统文件选择器，无额外存储权限，不访问账号或应用更新凭据。不自建服务器、不实现设备发现或传输协议；Android 系统备份配置保持原样，系统备份和设备迁移是否执行由系统及厂商决定，不代替用户可控的文件备份。

## 换机步骤

### 旧手机：导出并传递

1. 「导出完整药箱」：页面显示已保存记录数与照片引用数；选择保存位置，生成一个 `pharmacy-backup-日期时间.zip` 文件，包含全部已保存药品资料及照片。空药箱不能导出，但可导入。建议保留多个日期的备份，不覆盖唯一备份。
2. 写入后回读所选文件，流式核对大小与 SHA-256，字节一致才显示「备份已保存并校验」。结果显示实际文件名、记录数、去重后照片数与大小。损坏/截断/额外内容视为失败；提供方无法回读则显示「已写入，尚未确认可读取」，不能当作已校验的备份。
3. 在系统文件管理器中找到文件，通过附近分享、USB／电脑或自行选择的云盘传到新手机。App 不自动分享或上传；回读成功不代表云盘已上传完成。
4. **新手机导入并核对药品、余量、有效期和照片前，不要卸载旧应用或清除数据。**

### 新手机：校验、导入并核对

1. 「选择备份文件导入」：完整读取校验，展示备份时间、记录/药品组/去重后照片数、本机已有数量、预计新增和重复数。仍兼容旧 v1/v2 ZIP，不改变备份格式。
2. 「确认合并导入」：重新核对现有记录，仅添加缺少的库存；不更新、覆盖或删除现有药品。取消或校验失败不改药箱。空备份提示没有记录；全部重复时无需再次导入。
3. 导入完成显示实际新增、跳过及为新增记录导入的去重照片数；「查看药箱并核对」清除搜索/筛选，方便查看完整药箱。完成写入不等于用户已核对成功。
4. 相同记录（含关联关系）再次导入会跳过。相同药名但资料、余量、日期、时间或照片不同的记录作为独立库存保留；不会靠药名覆盖，也不会以时间较新者替换。导入后可自行核对是否需要移除旧记录。

这是一次性备份/迁移，不是实时同步或历史回滚。不新增密码管理、定时后台备份、覆盖式恢复、账号或云服务依赖。

备份涵盖：名称、有效期原文、功效、备注、余量/单位、OCR 原文、创建/更新时间、标签、15 项药品/说明书字段，以及有序照片。未知余量与 0 分开；旧单位、未知日期及文字内部换行保留，药品组关联随v2备份保留。**未保存草稿、撤销历史、相机临时文件、安装包和登录凭据不在备份中。**

## 隐私与保管

- 备份**未加密**，包含个人健康信息、药品、位置与备注。不要公开上传或发送给不可信的人。
- 保存到系统文件选择器中的云盘时，文件会由该云盘服务处理；本应用没有自行后台上传，但不保证云盘离线或私密。
- 应用不记录备份内容到日志、不嵌入账号/令牌。只向用户选择的文件 URI 写入，原药箱保留。
- 写入空间不足或文件服务断开时可能留下不完整的目标文件；应用提示备份未完成，用户应删除该文件，不能把它当成成功备份。App 无权承诺任意文件提供方的原子写入。
- 清缓存不会删除用户选定目录里的完整备份；卸载/清数据会删除本机药箱，所以必须先确保备份已成功。新旧安装签名不一致时，在旧版本导出后再规划迁移，不直接卸载。

## 格式与校验

当前备份 v2 为 ZIP，兼容读取 v1（未包含分组关系）：

- `cabinet.bin`：UTF-8 长度前缀的有版本清单，使用固定资料字段顺序，v2在每条记录后追加组UUID/名称，不依赖数据库文件或本机路径；拒绝未知版本、截断、非法长度、非法余量及未支持尾部数据。
- `photos/<sha256>.bin`：原始照片字节，SHA-256 命名；同一照片可在多个库存中复用，导出只保存一份。图片显示依赖原始文件内容，不依赖扩展名。
- 导入只允许上述精确命名，拒绝重复项、目录、任意路径、缺图、额外图片、CRC/哈希错误；使用私有随机暂存目录，不按 ZIP 文件路径解压。
- 上限：2000 条记录、每条 12 张照片、单张照片 20 MiB、清单 16 MiB、单项文字 1 MiB、压缩文件及总解压内容 512 MiB。不是任意规模数据库的备份工具。为保留旧记录，导入不要求旧日期/单位满足现行录入格式。
- 照片无法读取时**整个导出失败**，不偷偷生成缺图备份；不自动删除缺失的照片链接。
- 导出先制作完整本地快照，再写系统选定位置。恢复先校验，确认后在 Room 事务中插入；不更新现有行。恢复失败回滚插入并删除本次创建的照片，不触碰旧照片。
- 文件与数据库不是跨资源原子事务：若设备在复制图片与提交数据库之间突然断电，可能留下未引用的新照片，但不会清空已有药箱。后续单独清理不在本次范围。
- 重复判断按完整记录值与有序照片内容哈希，忽略本机库存 ID、URI，保留分组UUID与组名；详情见 [medicine-groups.md](medicine-groups.md)。备份不是同步/版本回退工具；测试版改了数据再恢复旧备份不会自动撤销该改动。

## 验证与边界

保留 4 个必要备份 JVM UT：完整字段/旧值往返，照片归档往返与重复身份，恶意路径/缺图/损坏照片拒绝，数量/大小边界。换机功能增加 1 个目标文件回读校验 UT，覆盖跨缓冲区一致内容、截断、额外内容、同大小篡改和空文件。保留其他核心规则测试，不新增 UI/仪器框架、第三方归档库或依赖。

构建与 Lint 只能验证编译/静态问题，UT 不代表 Android 文件提供方、实际数据库事务及进程/设备中断已实测。专用模拟器的实际导出、清除测试记录后恢复、照片查看和重复恢复需在本次清空测试数据获明确授权后验收；未获授权不自行运行或声明通过。
