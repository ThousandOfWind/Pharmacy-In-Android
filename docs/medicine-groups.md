# 药品组与独立库存

## 分组不是合并药品

同名、同品牌不同有效期的多盒药很常见。药品组只提供导航关联；每条库存的品牌、规格、批号、有效期、位置、余量、照片、标签与说明书都独立保存。不跨单位求和，不对整个组扣减，不表示不同品牌/规格可替代。

- 首页按**用户明确关联**的药品组显示，组内汇总库存条数、已填写品牌数与异常状态。未分组记录继续单独显示；旧数据不自动按同名合并。
- 搜索可匹配组名及每条库存原有字段；有效期/标签筛选先匹配独立记录，首页分组显示匹配条数与总条数。点进组时展示全部库存并解释当前匹配数量，防止一条正常库存掩盖组内过期库存。
- 组内按有效期早到晚排列，未知日期在后；点击具体库存才能更新余量或编辑。
- 详情顶栏「关联」可关联到已有组/另一条未分组库存、创建组、移出组。关联前提示核对通用名/剂型；只改变关联字段，不改原药品资料。
- 创建组时可填写80字符以内的名称。内部使用随机UUID，不把同名组自动视为同一个。
- 组内「添加一条新库存」仅预填组名和关联；**不复制有效期、余量、品牌/规格、照片或说明书**，避免拿上一盒信息误填新盒。
- 若新录入的通用名、品牌和规格明确且与已有分组库存一致，显示可选关联提示，用户主动确认才关联。资料不完整或不同品牌时用详情里的手动关联，不依据OCR自动归组。

## 迁移与备份

Room版本6通过5→6显式迁移新增 `group_key`、`group_name` 两个空文本列；旧库存、照片、余量和资料保留并保持未分组，不推断分组。

备份v2在每条记录末尾加入关联UUID和组名，仍能读取此前v1无分组格式。恢复保留关联；同名但不同UUID的组不合并。若备份组UUID与本机组名称冲突，导入使用确定性的新UUID分开，反复恢复不会无限生成新组。分组不同的库存作为独立记录保留，不覆写现有关联。

## 范围与验证

本次不增加药品知识库、自动成分比较、跨品牌替代、整组用药建议、批量余量编辑或库存合并。新增2个必要纯规则UT覆盖同名不自动合并、组内日期顺序、备份组冲突与关联往返；原核心测试保留。

实际Android新旧数据库迁移、组内导航/返回、关联/移出、筛选提示及导出恢复分组关系需专用模拟器验收；构建/UT不代替设备实测。
