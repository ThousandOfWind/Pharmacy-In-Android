# 拍照候选归类与框选重识别

## 目标

减少抄写：在本地 ML Kit 中文 OCR 后，按照片中明确的药品资料/说明书标题生成候选。用户核对照片后采用，不能把 OCR 错字解释成准确的药品知识，也不从网上查来的另一版本说明书补齐内容。

- 未带名称标签、但具有常见剂型后缀的独立文本行，可作为用户选择的药名候选；不自动当成唯一药名。
- 明确标题对应通用名、品牌/商品名、规格/包装、厂家、批准文号、批号、成分、用法用量、禁忌、不良反应、注意事项、相互作用、贮藏及修订日期等。
- 标签匹配可忽略标题空白、兼容部分繁体标题；值保留 OCR 原文，不偷偷纠正药名、温度或剂量。
- 未识别标题、重复冲突内容和超长资料不静默覆盖，保留原文供核对。说明书章节在下一个括号标题停止；单行冒号资料不吸收无关后续行。
- 「采用空白资料」只填空白的名称、明确到期日期和基本资料，不改手工填写，不推算余量、单位、位置或标签。
- 说明书安全条目显示原候选全文，逐项「核对后采用」，不批量写入。最后仍需确认核对，保存不自动发生。
- 月份到期按月末计算；生产日期、修订日期及“30个月”等期限不当成库存有效期。支持 `20260303` 紧凑日期和 `2029 年 02 月` 空白；遇到批号/生产日期/有效期标签列后跟值列，只在完整且类型符合的组中按顺序配对，不完整/无效/额外日期不取候选。
- 品牌/商标、生产商/厂家、药品上市许可持有人/生产企业等标题可归类；独立完整中文药企公司名、`每盒20粒` 等明确包装数量可生成候选，不把剂量或包装数量当余量。无标签品牌短词不猜填，可复制原文或指定品牌框选。
- 常用标签以明确章节为依据：用途来自适应症，用法用量中的口服/外用、贮藏中的冷藏/遮光/避光。含否定/禁止字样的句子不推荐；药名、禁忌、注意事项不作为来源，不自动推荐家庭常备/出行备用。依据可复制，标签逐项采用，保留已有标签并遵守8个上限。

## 核对操作与原文复制

1. 「① 核对识别结果」以字段名和结果卡片展示，品牌/厂家/规格等不用先展开才能看到。
2. 「② 点击按钮填入资料栏」使用填色/边框按钮，与结果文本区分。采用只填空白栏，说明书安全条目逐项采用，标签也逐项采用并显示已采用状态。
3. 原文和候选支持长按选择/复制；「粘贴原文 → 指定资料栏」只在点击粘贴时读取剪贴板，可编辑后指定空白名称、日期、品牌/厂家/规格等基本资料，不直接归入安全条目。日期仍校验，生产日期标签不当有效期。
4. 「③ 保存前确认」独立带边框核对框，提示勾选后再保存。

## 已保存记录的再次编辑

- 默认「基本资料」分页，名称、有效期、余量、位置、通用名/品牌/规格/厂家/批准号/批号、标签和备注均直接可修改，没有嵌套「更多」折叠。
- 「说明书」分页直接展示各记录栏；「照片 / 原文」集中照片管理、补拍及历史原文复制。分页改动属于同一草稿，底部固定保存，返回仍可放弃全部改动。
- 初始编辑只加载已保存资料，不把历史原文当新候选来源，不显示空候选卡。只有本次补拍/重识别生成新原文或候选时才显示候选；其他分页提供明确的前往核对按钮。
- 已保存资料的手工修改保留已核对状态，不要求重复核对旧OCR。新增识别/采用、复制归入、旋转/删除照片会清除核对状态；照片/原文分页提供确认，保存出错会转到需要修正的分页。

## 照片旋转与删除

- 添加/编辑页照片下方提供「旋转 / 删除 / 识别」菜单，放大页也可旋转、框选或删除。详情只查看，通过编辑页保存变更。
- 旋转按90°顺时针，通过新私有副本更新 EXIF，不损失像素、不改动旧记录文件。缩略图、放大、框选和整图重识别使用旋转后的方向；不自动重识别覆盖候选。
- 删除先确认，只移除草稿引用，保存后生效；放弃编辑保留旧记录。保留原文件、已填写资料及历史原文（非物理擦除）。当前候选没有逐照片溯源，删除清空所有待采用候选；可重新识别保留照片，不留下已移除图片的可采用候选。
- 识别/旋转/保存期间禁用照片修改；失败保留原图，返回后迟到结果不写入新草稿。

## 框选重识别

编辑/添加页的每张照片旁有「框选重识别」。打开后在图上拖动框住文字，再指定归入字段，例如药名、有效期或说明书段落；只重新识别选区。

- 比例坐标基于屏幕实际显示的图像，不包括周围留白；预览与裁切采用同一方向的图片，处理 EXIF 旋转/镜像。
- 框选可重画，原图不改，不新增一张覆盖原图的照片。空选区禁用识别；重试仅更新指定字段的候选，空识别保留原候选。
- 累计 OCR 原文上限为 50000 字符；超限时明确提示并拒绝本次候选，不静默截断核对来源，保留原图和已有结果。
- 框选解决背景/多药盒干扰和字段歧义，不能恢复模糊、反光或丢失的笔画；结果仍作为待核对候选，已有填写不覆盖。
- 当前是拖动框选，不承诺无障碍手势已验收、透视矫正或自动提升所有小字识别率。保留手工编辑与原图查看。

## 固定图片实测（不是总体识别率）

使用应用同版本的 ML Kit 中文识别器在专用 Android API 34 模拟器上识别公开图像。临时 probe Activity、样本、OCR 日志与截图只留在被 Git 忽略的 `build/`，不随 App 发布、不加入测试框架，也没有用户药箱数据上传。

| --- | --- | --- | --- |
| 必理痛香港药盒 | [厂商页面](https://www.panadol.com/zh-hk/products/adult/everyday-pain-relief/panadol-carplets/)，1000×1000 商品摄影 | 标识被读成“更理痛”，无名称候选；小字有误读 | “主治”可成为明确标题候选，但药名没有可靠文本，不擅自修成“必理痛”；24粒不是剩余数量 |
