# 隐私说明

适用范围：当前仓库构建的 Pharmacy-In-Android 药箱应用。本文说明实际功能的数据处理边界，不是隐私同意记录，也不声称已完成商店或监管合规认证。应用内“更多 → 关于 → 隐私说明”提供同一份离线文本；依赖或功能变化时应同步更新。

## 本地药箱与权限

- 药名、生产日期、有效期、余量、标签、位置、资料、说明书、备注及 OCR 原文主要保存到本机应用私有数据库；照片保存到私有目录。部分填写草稿由 Android 保存以恢复页面。药品及位置等内容可能涉及健康或其他敏感信息，请只录入有权处理的资料。
- 相机权限只在用户选择拍照时申请；拒绝后仍可手动录入或使用系统照片选择器。照片选择器仅授予所选内容的访问权限；备份使用系统文件选择器，不申请全盘存储权限。
- 本应用没有账号注册、广告 SDK、购物导流或开发者自建的药箱云同步服务；不把记录自动发送到项目仓库。这不等于系统及第三方 SDK 都绝不通信。

## OCR 与 Google ML Kit

应用使用随包的 ML Kit 中文文字识别。根据 [ML Kit 官方条款与隐私说明](https://developers.google.com/ml-kit/terms)，输入图片、文字及识别结果在设备上处理，不发送给 Google；SDK 可能联系 Google 获取修复、模型或硬件兼容信息，并向 Google 发送 API 性能和使用指标。开发者需要依法告知此处理。相关传递依赖包括 Google Play services、Data Transport 和 Firebase components 等；存在这些库不等于本应用使用了 Firebase Analytics 或账号登录。

这份官方说明不是本机网络抓包结果，也不能据此承诺特定设备、系统或 SDK 版本的所有通信细节。尚需核对 [Android 数据披露说明](https://developers.google.com/ml-kit/android/data-disclosure)与最终设备行为；本次不新增 SDK 同意拦截或改变其初始化/收集行为。不同意或不使用 OCR 时可手动录入，但这不是“关闭所有 SDK 网络行为”的开关。Google 的处理还受其 [隐私政策](https://policies.google.com/privacy)及 [API 条款](https://developers.google.com/terms)约束。

## Android 系统备份与导出

当前启用 Android 系统备份：药箱数据库和照片未全部排除，可能随系统设置被云备份或设备迁移处理，具体由系统/设备服务决定。应用没有提供关闭系统备份的内置开关；需在设备设置中管理，不能承诺所有厂商一致。

手动 ZIP 备份未加密，包含已保存的药品及照片。用户选择云盘等文件提供方时，该服务会处理文件；应用不保证其离线或私密。导出的副本不随卸载自动删除。备份不含未保存草稿、相机临时文件、安装包、Azure Key、连接配置或 AI 会话，详见[备份说明](backup-restore.md)。

## GitHub 更新与外部网页

只有用户点击“检查更新”或“下载更新”时，更新客户端才请求公开 GitHub Release/CDN 文件：检查直接读取 `releases/latest/download/update.json`，不调用 REST API，不附带药箱记录、GitHub 登录凭据或 Token。网络服务可能处理请求 IP、时间和客户端标识，受 [GitHub 隐私说明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)约束。下载缓存仅用于 APK 校验和用户请求的系统安装。

点击“项目主页”或“浏览器下载 / 发布说明”交给外部浏览器；浏览器可能使用自己的账号、Cookie 和隐私设置，本应用不读取这些数据。浏览器下载不经过应用内校验；请只选择官方附件，不卸载旧应用或清除药箱。离线阅读本文或许可通知不发起浏览器或网络请求。

## 可选 Azure AI

配置并主动使用助手时，问题、有限最近历史发送到用户选定的 Azure 资源；问题本身可能含用户主动输入的健康信息。“本次允许查询库存基本资料”默认关闭，开启后只读工具可发送最多每次 10 条名称、品牌/通用名、规格、位置、有效期、余量及单位，不发送库存中的备注、功效、照片、OCR 原文或说明书。关闭授权不能撤回之前已发送或保存在历史中的内容。

Key 在本机由 Android Keystore 加密，不进入系统/药箱备份；连接元数据及 AI 会话也排除系统 cloud/device-transfer 备份。删除连接或会话不撤销 Azure 远端 Key 或已收到的数据。服务地域、保留、安全监测及可能的跨境处理取决于所用 Azure 资源和适用条款，不能保证“零保留”或境内处理。详见[助手说明](azure-ai.md)及 [Azure 数据隐私说明](https://learn.microsoft.com/en-us/legal/cognitive-services/openai/data-privacy)。

## 查看、删除与反馈

- 可在应用查看、编辑和移除药品，单独删除 AI 会话及连接。新录入默认在成功保存后只长期保留选中的药品图，其他本次识别图按引用关系清理；旧多图记录不自动删除，需显式确认。照片清理不删除相册原文件或其他记录/草稿/可撤销记录引用的文件，清理失败或异常退出可能留有临时副本，详见 README 的照片保留说明。
- 移除记录不承诺立即擦除所有已复制照片、暂存文件、系统备份或导出副本；短时撤销也会保留恢复所需内容。
- 清缓存不等于清除药箱。卸载或清除应用数据会删除本机药箱及凭据，请先确认备份；外部副本和服务已接收内容须分别管理。不要为解决更新失败直接卸载。
- 一般功能/隐私说明问题可通过项目主页反馈，但公开 issue 不适合发送药箱、照片、证件、Key 或私人联系方式。本项目没有配置专用的个人数据请求收件渠道；不要将公开 issue 当作私密投诉入口。
